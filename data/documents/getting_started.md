# Getting Started

## Creating an account

Users can create an account by opening the registration page and entering their email address and password. The system sends a verification email before activating the account.

## Resetting a password

If a user forgets their password, they can select Forgot Password on the login page. A password reset link is sent to their registered email address. The link expires after 30 minutes.

## Contacting support

Users can contact support through the Help Center. They should include a description of the problem and any relevant error message.
